# EKT AI-консультант

Прототип ИИ-помощника для каталога ekt.kz. Он ищет товары по артикулу или названию, показывает актуальные данные карточки, отвечает на вопросы об оплате и доставке, подбирает кандидатов-аналогов и добавляет позиции в демонстрационную корзину только после явного подтверждения клиента.

## Что реализовано

- плавающее окно чата поверх страницы каталога;
- загрузка товаров из API ekt.kz;
- серверный поиск по артикулу и названию в первых страницах каталога;
- получение цены, остатка, складов и характеристик через детальную карточку;
- вызовы функций через OpenAI Responses API и модель `gpt-4.1-mini`;
- защищённый сценарий: предложение → подтверждение → повторная проверка остатка → корзина;
- адаптивная страница `/cart` с самостоятельной демонстрационной корзиной.

## Архитектура

Браузер обращается только к серверным маршрутам Next.js. Сервер хранит доступ к API ekt.kz и OpenAI, выполняет поиск, читает детали товара и передаёт модели только подходящие результаты. В браузер не попадают Basic Auth и ключ OpenAI.

```text
Браузер → Next.js API → API ekt.kz
                    └→ OpenAI Responses API
Браузер → localStorage демонстрационной корзины
```

## Запуск

1. Установите Node.js 20 или новее.
2. Скопируйте `.env.example` в `.env.local` и укажите ключи.
3. Выполните:

```bash
npm install
npm run dev
```

Откройте `http://localhost:3000`.

Для итоговой проверки:

```bash
npm run build
```

## Переменные окружения

`EKT_API_USER` и `EKT_API_PASSWORD` — Basic Auth для каталога ekt.kz. `OPENAI_API_KEY` — ключ OpenAI. `EKT_MAX_PAGES` ограничивает число страниц, которые сервер читает при поиске, чтобы не загружать весь каталог при каждом запросе.

`.env.local` исключён из Git. Не передавайте его содержимое в браузер, Git, README, скриншоты или презентацию.

## Данные и ограничения

Каталог: `https://ekt.kz/api/products`, детали товара: `https://ekt.kz/api/products/detail?id=ID`. Цена, остаток и свойства отображаются только из этих ответов. Когда поля противоречат названию или описанию, ассистент обязан предупредить пользователя.

Корзина в этом MVP демонстрационная: API для изменения настоящей корзины ekt.kz не предоставлен. Для внедрения на рабочий сайт нужно подключить внутренний endpoint корзины ekt.kz и проверку сессии покупателя. Загрузка Excel, Word, PDF и JPEG сознательно не входит в первый MVP.

## Сценарий для жюри

1. Откройте чат и спросите: «Есть ли 027228? Покажи характеристики».
2. Попросите предложить аналог для отсутствующего товара.
3. Спросите об оплате или доставке.
4. Напишите: «Добавь 3 штуки в корзину». Покажите, что корзина не меняется до кнопки подтверждения.
5. Подтвердите действие и откройте `/cart`.
6. Повторите с количеством больше остатка: приложение остановит добавление и назовёт доступное количество.
